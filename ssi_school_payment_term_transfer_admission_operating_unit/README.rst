=========================================================
School Payment Term Transfer - Admission - Operating Unit
=========================================================

Operating Unit support for the Admission path of SSI School Payment Term
Transfer. Derives ``operating_unit_id`` on ``school_payment_term_transfer``
from the targeted Admission's own Operating Unit, so Admission-path
documents get the same Operating Unit access control and filtering that
Enrollment-path documents already get from
``ssi_school_payment_term_transfer_operating_unit``.
